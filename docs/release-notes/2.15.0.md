## Build and validation

The download is an ad-hoc signed universal macOS build for Intel and Apple silicon. Accessibility, Input Monitoring, and Cursor Helper consent are still required where applicable. Automated validation runs on Intel macOS 15; a complete real-device acceptance pass across macOS versions, Apple silicon, and all editors has not been completed.
